## 🚀 Projets à découvrir

### 🤖 IA & assistants

- **[Docverse](https://github.com/ngoujon/docverse)** — RAG souveraine : discutez avec vos documents (PDF, scans, audio, pages web…) sur une chaîne 100 % européenne — hébergement OVHcloud, IA Mistral, transcription Whisper locale.
- **[Assistant OpenSpace](https://github.com/ngoujon/assistant-openspace)** — App macOS qui monte une *équipe virtuelle* (orchestrateur, chefs de service, spécialistes) de sous-agents Claude pour produire un livrable Markdown.
- **[Assistant Todoist](https://github.com/ngoujon/assistant-todoist)** — Un assistant conversationnel macOS branché sur Todoist via MCP pour planifier vos tâches.

### 🍎 Apps macOS natives

- **[Sommeil](https://github.com/ngoujon/sleep-tracker)** — Transforme votre export Apple Santé en score de sommeil, niveau de stress et tendances cardiaques. 100 % local, algorithmes documentés.
- **[MultiPlash](https://github.com/ngoujon/mac-background)** — Une page web en fond d'écran, différente sur chaque écran. Swift + AppKit, zéro dépendance.

### 🎨 Web

- **[Design Systems Gallery](https://github.com/ngoujon/design-system)** — Galerie de 20 design systems, chacun présenté à travers un faux site complet.
- **[nicolas-goujon.fr](https://github.com/ngoujon/nicolas-goujon)** — Mon site pro : React + TypeScript, API de contact Laravel, dockerisé.
- **[JDR D&D](https://github.com/ngoujon/jdr-dnd)** — Un side-project autour du jeu de rôle.
